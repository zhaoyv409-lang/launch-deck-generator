# 流动网页演示

本轮新增操作及验收范围见 [构建版对齐记录](../docs/ALIGNMENT_PROGRESS.md)。图片支持整页/逐张角度、比例、显示方式、图注和大图；表格最多 13×8、每格 120 字；编辑栏可调宽，项目可改名，备份可恢复，菜单支持首页/教程/主题。HTML 内嵌素材和字体，素材总计超过 150 MiB 时提示改用 ZIP；PPT 使用静态底色和视频封面或首帧，字体需接收端安装。

Windows 使用系统 Chrome 验证：先设置 `$env:PLAYWRIGHT_CHANNEL='chrome'`，再运行 `npm run test:e2e`。性能测试额外设置 `$env:PERF_REPORT='alignment'`，运行 `npm run test:perf`，不要与功能回归并发。

首次进入完整首页，点击“开始制作”打开八屏软件介绍示例。已保存的作品继续保留；可通过“更多操作 → 载入软件介绍示例”恢复同一份参考内容，替换前会确认并备份。按需打开编辑浮层，改好即可收起播放。

## 开发与构建

建议 Node 22.12+ 或 24+（满足 Vite 8 要求）。

```bash
cd web
npm ci
npm run dev
```

默认地址：**http://127.0.0.1:5173/**。`predev` 自动构建播放器再启动 Vite；端口被占用可通过 `--port` 指定，E2E 使用 5373。

```bash
npm run typecheck
npm run lint
npm run build
npm run preview -- --host 127.0.0.1 --port 4173
```

`build` 同时生成编辑器 `dist/` 与独立播放器，播放器原件放在 `public/player/`，并同步到 `dist/player/`。单独更新播放器可运行 `npm run build:player`。播放器的 JS / CSS 均本地打包，运行时不请求 CDN。

## 编辑与播放

- 点击“编辑当前屏”打开右侧浮层；顶层为“当前屏 / 整场设置”。当前屏下有文字与脚注、图片与视频、图表与表格、文字样式、入场与动效、管理这一屏；整场设置包含作品名称、背景与配色、切屏转场。面板覆盖画面，不压缩画布；桌面默认宽 424px，可拖动或用键盘调整。
- 先选版式，再替换内容。35 个预设覆盖文字、图文、截图、视频、图表、表格、步骤与收尾。最多 2 标题、2 文本、6 图；字号自动适配并可在 0.6–1.6 倍调整，保留固定布局。
- 每屏可写一条脚注（页脚小字），结束页用“结尾收束”版式：独立黑色舞台上呈现字幕，停留后完整淡出到黑；编辑时保持文字可见。折线、柱状和饼图使用 Recharts；最多 12 分类、3 系列，饼图使用第一系列、负值按零显示。
- 新建时先选择版式；内容面板“换个版式”也可切换。切换前会保存 一份 `before-preset` 备份，再按对应数量保留内容。字号按字数自动适配，适合短标题与简短说明。
- 图片可多选或直接粘贴；达到六张后停止添加。支持独立替换、前移与删除。选择更多图片时只保留容量内的文件。
- 视频使用浏览器原生播放器，支持静音、循环和封面。离开场景前暂停；返回该屏后按播放器按钮重新播放。格式取决于浏览器解码支持。
- “整场设置 → 背景与配色”提供 8 类背景、21 套色板、Hex 颜色、背景速度与暂停。背景包括流动渐变、柔雾颗粒、云朵、层次云、纯色、流线、烟环、星点。色板默认只调整当前屏文字色，可选择应用到全部屏。文字样式提供 14 个字体选项；界面使用参考构建中的 GT Standard L，本地展示字库与回退顺序也按参考恢复。Hex 输入回车或离开焦点应用。
- 不适用的设置会禁用：收尾固定黑场、整屏视频覆盖背景时不能修改背景；纯单图 / 纯影像不显示脚注，没有主标题时不能选择文字出场；关闭灵动后不能选择动效或重播。纯色背景仅使用第一个色位，层次云不使用第三个色位；暂停背景后需先恢复才能调节速度。收尾使用浅色文字，深色配色不可选。
- 右上角操作区使用独立实色背景，深色、浅色、云朵和收尾背景下均可读取；独立播放器共用样式，全屏时操作区保持清晰。
- “灵动”默认采用自然淡入（Motion）、静置图片与柔和切屏（Swiper Fade，450ms）；背景缓慢流动；云朵背景最多绘制 230400 像素、每秒最多 30 帧，编辑、收尾及页面不可见时停止逐帧绘制。主标题保留 BlurText 聚焦 / 掠入选项；图片按当前参考构建使用直接相框、旋转、比例、图注和大图查看。参考构建的这些图片不走 TiltedCard 渲染路径；小字只整段淡入，脚注直接呈现。可关闭这一屏灵动，或重新播放当前屏。减少动态效果偏好会自动暂停背景与持续轻浮，并显示清晰静态文字。
- 底部导航只显示页码，不需要逐页起名；＋先挑预设再创建下一屏。编辑浮层底部支持复制、前后排序与确认删除。始终保留至少一屏。
- 方向键、空格和滚轮切换整屏内容；全屏按钮进入原生 Fullscreen API，Esc 退出。转场提供纵深漂移、柔和淡入、卡片推进、神奇移动。前三者使用 Swiper；神奇移动按参考版保留各页内容，并在 Swiper 转场事件中匹配元素位置。减少动态效果时关闭转场动画。
- 旧表格页迁移时仍保留，信息对照组合中可编辑单元格。

## 保存与旧版兼容

Dexie 数据库 `stage-workbench` 中，项目存于 `projects`，真实媒体 Blob 存于 `media`，没有持久化临时 Blob URL。刷新后重新建立 URL。

v0.1 项目升级前会完整备份到 `projects/v0.1-backup`，再映射到受限场景模型；已有标题、正文、图片与视频继续保留。运行包导入前也先保存 `before-import-backup`。读取失败不会覆盖为初始内容，保存失败保留内存编辑并提供重试。

本地数据跟随浏览器和来源：`127.0.0.1:5173`、`localhost` 和其他端口互相独立。请固定开发地址；要搬到其他来源，使用 ZIP 包。清除站点数据会清除本地项目。

## 打包到其他电脑运行

1. 点击“打包带走”，得到一个 ZIP，包含当前完整项目、所有引用图片 / 视频、本地播放器、许可证及启动说明。
2. 完整解压，目标电脑需有 Node.js 18+。无需源代码、npm install 或原浏览器 IndexedDB。
3. 在解压目录执行 `node start.mjs`。Mac 也有 `start.command`，Windows 有 `start.bat`。
4. 浏览器打开打印的地址，默认 `http://127.0.0.1:4177/`；端口被占用会自动换空闲端口。方向键 / 空格 / 滚轮切屏，F / 按钮进入全屏。
5. 如需继续编辑，回到编辑器，点击“打开运行包”导入 ZIP。

只需一个提供静态文件的本地启动器，没有业务后端、云数据库、账号或网络服务。把 ZIP 交给另一个 Agent 时，让它在解压目录执行 `node start.mjs` 并打开打印的本地地址即可。

播放器要求通过本地 HTTP 打开；不将双击 `file://index.html` 当作可运行方式。解压目录不要只搬 HTML，图片、视频和 assets 需要一并保留。

## 验证

```bash
npx playwright install chromium
npm run test:e2e
npm run test:e2e -- --repeat-each=3
```

浏览器测试覆盖文字入场、常驻背景、内容数量上限、编辑、真实媒体、保存恢复、失败重试、旧数据迁移、全屏、ZIP 导出 / 独立来源启动 / 导回、离线 HTML、PPT 结构及新增对齐功能。ZIP 场景真实解压运行启动器，阻断外站请求并确认播放器未创建 IndexedDB。

同时启动参考构建（5174）和源码构建预览（5373）后，运行 `npm run test:reference` 比较代表性页面，再运行 `node scripts/compare-transitions.cjs` 对比四种转场。可用 `REFERENCE_URL` / `SOURCE_URL` 覆盖默认地址。脚本使用隔离浏览器，不清除正在使用的作品；截图和 JSON 写入本地 `evidence/`。当前验收范围与限制以 [构建版对齐记录](../docs/ALIGNMENT_PROGRESS.md) 为准，旧性能报告不代表这次视觉对齐后的结果。

详见 [VALIDATION.md](VALIDATION.md)、[THIRD_PARTY.md](THIRD_PARTY.md) 和 [COMPONENT_SOURCES.json](COMPONENT_SOURCES.json)。

## Agent 可以调用

浏览器中的 `window.flowAgent` 提供 `inspect()`、`listPresets()`、`apply()`、`addScene()`、`setBackground()`。Agent 可以直接交出内容：`addScene` 接受每屏的大字、小字，以及 base64 data URL 形式的图片和视频，一次调用就能从零搭出一屏，写入 IndexedDB 后刷新仍在。

ZIP 中包含 `agent.mjs` 和配置样本，另一台电脑可运行 `node agent.mjs apply agent-example.json` 修改已有屏，或把本地图片/视频路径写进 JSON 后运行 `node agent.mjs add new-scene.json` 新建一屏——素材会被复制进运行包并登记媒体清单。两者都受同一套固定预设、数量、颜色与效果规则约束。详见 [Agent 调用说明](../docs/AGENT_API.md)。

## 性能诊断与本轮优化

- `npm run analyze`：生成 `dist/bundle-report.html` 静态体积报告。
- 开发地址加 `?scan`：按需开启 React 重渲染诊断；生产环境不加载。
- `PERF_REPORT=after-phase-1-2 npm run test:perf`：单独运行性能压力脚本并生成 JSON。不要与 E2E 或其他性能脚本并发运行。
- 图片上传会保存 3840 / 1920 / 400 三档；舞台与参考构建一致使用主图，编辑器使用 400 缩略图，1920 档保留在媒体与导出记录中；GIF、SVG 和识别到的动画图片保留。
- 编辑面板新增撤销/重做；文本框内保留浏览器原生撤销，其他位置支持 Ctrl/⌘+Z 和 Ctrl/⌘+Shift+Z。
- 打包时支持文件保存接口的浏览器直接写盘；其余浏览器仍下载 ZIP。未使用的阿里妈妈字体不带进运行包。

实施范围、验证口径与剩余任务见 [优化实施记录](../docs/OPTIMIZATION_PROGRESS.md)。

Safari / WebKit 若在无痕会话出现“Error preparing Blob/File data”存储错误，请使用普通窗口打开编辑器。独立导出的播放器不使用 IndexedDB；引擎复现与验证范围见上述实施记录。
