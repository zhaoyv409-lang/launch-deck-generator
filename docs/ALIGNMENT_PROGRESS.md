## 按参考保留的行为

本阶段以现有构建的实际行为为准，不混入另行设计：

- 参考版分类逻辑将截图/报告相关版式列入“收尾”，因此“截图与报告”显示 0，“收尾”显示 10。源码兼容此结果，未沿用上一轮自行调整分类的方案。
- 首次载入八屏示例直接使用示例数据。第七屏示例的两个标题，在刷新并规范化为该版式后只保留一个；参考版也如此。本轮未悄悄修正这个差异。
- 配色默认只影响当前屏文字色；“应用全部屏”的选择持久化保存。
- 图片按参考直接相框渲染；保留的图片动效选项不意味着这些相框使用 TiltedCard。
- 神奇移动不再采用上一轮自行实现的、仅挂载当前页的近似动画；其页面挂载与事件触发顺序按参考恢复。
- 备份列表展示最近 12 份。存储用量、时间、作品内容和连接状态来自各自实际环境，不伪造为固定一致的数值。
- 参考包请求的 `/game/site-home.js` 不在提供的文件中，原包返回 404。源码中的完整首页使用应用内实现，不加入这个缺失请求。

## 导出与验证口径

PPT 使用参考导出布局。图表与表格为原生对象；背景为静态底色，视频使用封面或可解码首帧，字体不嵌入。保留了内部关系目标修复。默认八屏导出的 slide/chart XML 与参考比较未发现差异；这不等于验证所有 PowerPoint/WPS 版本的最终渲染。

HTML 为含运行时、素材和字体的单文件，已测试离线 file URL 的图片、字体和视频播放。大素材仍需 ZIP。ZIP 测试包括真实解压、独立来源启动、素材与字段保留、导回编辑及内部资源关系。

视觉对照使用同一台机器的 Chrome、相同视口与内容，隔离浏览器上下文。静态截图启用减少动态效果，等待字库、图片转换及页面更新；动态行为另外测试。截图结果不能外推为任意素材、分辨率和浏览器的逐像素保证。
